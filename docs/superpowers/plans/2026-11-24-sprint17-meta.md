# Sprint 17 — Meta (Lead Ads + CAPI) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (native, chosen by Mateus). Steps use `- [ ]`.

**Goal:** "Conectar com Meta" por equipe → leads de formulário direto no Rev → infra CAPI pronta (desligada).
**Architecture:** conta em `crm_integrations` (token system-user no Vault) → ativos em `crm_integration_assets` → filas genéricas `crm_inbound_events` / `crm_conversion_events`. Lógica pura em `_shared/meta.ts`; chamadas Graph em `_shared/meta-graph.ts`.
**Tech Stack:** Supabase Postgres + Vault + pg_cron, Edge Functions Deno, Vite/React/shadcn.
**Spec:** `docs/superpowers/specs/2026-11-24-sprint17-meta-integration-design.md`

## Global Constraints
- Graph API `v27.0` (constante `GRAPH_VERSION` em `_shared/meta.ts`).
- Toda chamada Graph com token leva `appsecret_proof = HMAC-SHA256(token, META_APP_SECRET)` em hex.
- Segredos edge: `META_APP_ID`, `META_APP_SECRET`, `META_LOGIN_CONFIG_ID`, `META_WEBHOOK_VERIFY_TOKEN`, `META_REDIRECT_URI`, `META_WORKER_SECRET`, `APP_URL`. Nunca em log/resposta.
- `leadgen_id` / `lead_id` **sempre string** (17 dígitos > `MAX_SAFE_INTEGER`). Nunca `Number()`.
- `origin === 'backfill'` ⇒ **sem** `dispatchConversationOpen` nem saudação automática.
- Textos de tela/comentários em português; código em inglês. Sem `db push`; migration pela Management API + `migration repair`.

## Review Focus
1. Página já ativa em outra equipe → ativar falha com mensagem clara (SQL test T2).
2. `state` reusado, expirado ou de outro usuário → `connect` recusa (SQL test T2: `_crm_oauth_consume`).
3. Assinatura ausente/errada/corpo alterado em 1 byte → recusa (Deno test T1).
4. `signed_request` com payload adulterado → recusa (Deno test T1).
5. Erro 190 do Meta → integração em `error` com "Reconectar", não erro genérico (Deno test T1 `metaErrorMessage`).
